# TwinBuddy 邀约文案模板（真实数据）
# 依据：docs/invite-templates.md §3 模板规范
# 格式：scene.tone: <text>
# 变量：{partner_name} {deadline} {weekday} {time} {place} {action} {adj} {budget} {aa_or_buy} {contact} {pace}
# 拒绝品牌自指（无"TwinBuddy" / "路线可以按这版走"）

# ===== 旅行 trip =====
trip.casual: 我{weekday}{time}也想去{place}{action}，你{adj}顺路吗？预算 {budget}{aa_or_buy}，到时 {contact} 约时间？
trip.direct: {weekday} {time} {place}，预算 {budget} {aa_or_buy}，地铁口见。
trip.warm: 哇好巧我也想去{place}！{weekday} {time} 地铁口见？预算 {budget} {aa_or_buy}～

# ===== 美食 food =====
food.casual: 你收藏的 3 家里，鮨·初今晚 {time} 不用排队（人均 {budget}），约个人一起去？我 {pace} 出行，{aa_or_buy} 就行。

food.warm: 鮨·初 {time} 不用排队哎！约个人一起？人均 {budget} {aa_or_buy} 就行～

# ===== 健身 fitness =====
fitness.casual: 我 14 天每周 3 次肩背训练，要不要搭个伙一起？{time} 出门，楼下健身房见？
