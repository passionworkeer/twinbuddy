# Structure Cleanup Archive

This archive contains files retired during the July 2026 repository structure cleanup.

Archived groups:

- `legacy-root-node/`: root-level Node package files that did not represent the active frontend
- `legacy-docs/`: stale or conflicting documentation moved before current docs were rewritten
- `legacy-persona-engine/`: dead persona engine entrypoint that imports missing modules
- `legacy-scripts/`: batch scripts with stale absolute paths
- `react-frontend/`: previous React/Vite frontend archived before replacing it with the Vue Douyin shell

The active runtime paths are documented in the repository root `README.md` and `docs/ARCHITECTURE.md`.
